# customer_churn_prediction

# Project Overview
This project predicts whether a customer is likely to leave a company or continue using its services. It uses machine learning algorithms to analyze customer information and identify customers who may churn.

# Dataset
The project uses the Telco Customer Churn dataset, which contains customer details, service information, contract types, monthly charges, tenure, and churn status.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random forest
- XGBoost

# Machine Learning Algorithms
- Random Forest
- XGBoost

# Project Workflow
1. Load the dataset.
2. Perform data cleaning and preprocessing.
3. Explore and analyze the data.
4. Split the data into training and testing sets.
5. Train Random Forest and XGBoost models.
6. Evaluate and compare model performance.
7. Predict customer churn.

# Objective
The main objective is to help businesses identify customers who may leave their services and take steps to improve customer retention.

# Conclusion
This project demonstrates how machine learning can be used to predict customer churn and support data-driven business decisions.
